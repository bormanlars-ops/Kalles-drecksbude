# KALLE – DRECKSBUDE 🎮

Eigenständiges Godot-Android-Spiel, unabhängig von **Kalle Chaosbuddy**.

## Version 0.1 – erster Prototyp

Der Spielprototyp liegt als ZIP-Datei bereit. Nach dem Hochladen von `KALLE_DRECKSBUDE_0.1_Godot_Projekt.zip` ins Stammverzeichnis dieses Repositories startet GitHub Actions automatisch einen APK-Build.

> Status: Quellprojekt zusammengestellt, aber noch nicht mit Godot getestet. Ein erfolgreicher GitHub-Build ist keine Garantie, dass alle Spielmechaniken korrekt funktionieren.

### Ablauf
1. Auf **Add file → Upload files** klicken.
2. Die Datei `KALLE_DRECKSBUDE_0.1_Godot_Projekt.zip` hochladen und committen.
3. Unter **Actions → Build KALLE Drecksbude APK from ZIP** den Build verfolgen.
4. Bei Erfolg das Artefakt `KALLE-DRECKSBUDE-0.1-debug-APK` herunterladen und die ZIP entpacken, um an die APK zu gelangen.

Paketsignatur: Debug-Signatur, **nicht updatekompatibel** zu anderen Debug-Zertifikaten. Eigenständige Paketkennung: `de.boyka.kalle.drecksbude`.
